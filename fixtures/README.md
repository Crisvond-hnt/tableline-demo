# Fixtures

Everything here is made up. Northline is a fictional restaurant. The names, message ids, and reservation ids were written for the demo.

`emails/` is a stand-in for new, edited, and canceled booking notices. The settings screen on the real account can send those three. The body in these files is a contract written for the demo, because that screen did not show the message format. The Date header is stored as `source_message_time`. It is not a mailbox delivery time.

`thefork/` is a stand-in for a second provider's reservation event. It is not a response from TheFork's API. `messages/` are guest conversations. Nothing in this folder was exported from a booking platform, Instagram, or a mailbox.
